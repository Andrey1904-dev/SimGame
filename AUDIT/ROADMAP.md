# Дорожная карта: от текущего состояния до играбельной игры

Основано на фактическом состоянии кода (`AUDIT/SYSTEMS.md`) и реестре проблем
(`AUDIT/ISSUES.md`). Оценки — в «человеко-днях» одного разработчика, знакомого
с проектом; это не обещания, а порядок величины.

## Этап 1. Сделать проект запускаемым (P0) — 3–5 дней

Без этого этапа все остальные оценки бессмысленны: сейчас Unity не может открыть
репозиторий как проект.

1. **Создать Unity-проект** (0.5 дня)
   * `UnityProject/` с `ProjectSettings/`, `Packages/manifest.json`
     (`com.unity.ugui`, `com.unity.test-framework`), сцена `Main.unity`;
   * Active Input Handling = `Both`.
2. **Импортировать модули** внутрь `Assets/`, исключив `*/Tests/`, `*/Tools/`,
   `*/References/`, `*.csproj`, `*.md` (0.5 дня).
   * Критерий: Console чиста, ошибок компиляции 0.
   * Если ошибки есть — это первые **реальные** сведения о совместимости с Unity.
3. **Проверить исправленный P0** (0.5 дня)
   * `QuarterUnityAdapter.Build` теперь сначала очищает, потом фиксирует план
     (исправлено в `786c7fc`); в сцене `HasPlan == true` после генерации.
4. **Прогнать Test Runner** (0.5 дня)
   * EditMode: 5 наборов, ожидаемо 0 провалов;
   * PlayMode: `City/PauseTests`, 8 тестов, **ни разу не запускались**.
5. **Собрать билд** и убедиться, что он стартует (1 день, с запасом на сюрпризы
   IL2CPP/Mono).

**Критерий выхода:** пустая сцена + `CityBootstrap` → в иерархии 974 объекта,
билд запускается, Test Runner зелёный.

## Риски расписания

1. **Unity-компиляция не проверялась ни разу.** Может всплыть 10–50 ошибок
   несовместимости API. Буфер: +3 дня на этап 1.
2. **`System.Random` в IL2CPP** может дать другой город в билде → сохранённые
   координаты разъедутся. Чинится заранее (этап 6), но если отложить — станет
   P0 после первого релиза.
3. **Нет реального художника/ассетов.** Всё на примитивах; замена на префабы
   предусмотрена (`QuarterPrefabOverrides`), но время на арт не заложено.
4. **8 `PauseTests` ни разу не запускались.** Если они падают в Unity, это
   ударит по этапу 1 в самый неудобный момент.
