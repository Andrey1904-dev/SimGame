Прочитай `CODEX_START_HERE.md` в актуальном клоне Andrey1904-dev/SimGame и действуй по нему. 1. Обнови сведения о GitHub (main, PR и SHA), проверь Git и содержимое обоих проектов и действительные пакеты/сборки/дубликаты, не теряя локальные изменения.
2. Закрой Unity, создай и проверь полную внешнюю копию проекта с неотслеживаемыми файлами, `.meta`, сценами, Packages и ProjectSettings. При ошибке остановись.

7. Подготовь отчёт: Git SHA, путь копии и способ отката, изменённые файлы, команды и коды, результат компиляции и тестов, выполненные визуальные проверки, реальные ошибки, исправления и оставшиеся ограничения. Не выдавай вне-Unity проверки за Unity.
