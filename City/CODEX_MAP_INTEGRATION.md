## 2. Конфигурация карты

- Размер: **750×750 м** (не увеличен; уменьшать не потребовалось).
- Система координат: X — восток, Z — север/юг, начало (0,0) в углу. Квартал 250 не меняется.
- Улицы (вертикальные линии X): 20, 150, 270, 420, 505, 730. Горизонтальные (Z): 20, 200, 300, 470, 600, 738.
- Ширина проезжей части 7 м, тротуар 2.5 м с каждой стороны.
- Круговой перекрёсток: центр (270, 300).
- Схема зон:
  - север (Z > 600): 4 многоквартирных дома «bld-n1..n4» (стартовая квартира №67 в `bld-n4`), двор с дорожками, скамейками, площадкой;
  - юг (Z < 200): 3 панельных дома «bld-s1..s3» с парковкой и точками доставки; АЗС-1 (462, 66); ПВЗ `pvz-01` (85, 390);
  - восток (X > 600): 3 современных дома «bld-e1..e3» с премиальными фасадами; АЗС-3 (688, 530);
  - юго-восток: 5 частных домиков «bld-p1..p5» (4–6 по ТЗ);
  - центр: ТЦ «Горизонт» (com-mall), магазин shop-01, кафе, ресторан, одежда, стройматериалы, ломбард (com-pawnshop, над ним АЗС-4 на (85, 340)), бизнес-центр, бизнес-инкубатор, банк, мэрия, полиция, больница, курсы;
  - северо-восток: завод (ind-factory), склад-производство (ind-warehouse), погрузка и грузовые подъезды;
  - северо-запад: АЗС-2 (85, 680);
  - лесопарк: деревья и газоны на северо-западе и юго-западе.

Полные данные раскладки — в `Tools/district_layout_check.py` (таблицы `VLINES`, `HLINES`, `DRIVEWAYS`, вызовы `building`/`commerce`/`gas`) и в C#-генераторе (те же координаты).

## 3. Как запустить

Python-проверка (без Unity и .NET):

```
python3 City/Tools/district_layout_check.py
```

Ожидаемый результат: `OK: все проверки пройдены`, exit 0. Последний локальный запуск: 960 объектов, 63 solid, 20 зон, 82 дороги, 59 узлов, 10 МКД (С4/Ю3/В3), 5 частных домов, 24 точки, 46 точек доставки, 46 входов (все достижимы), 0 недостижимых, 47 деревьев, 188 фонарей, 104 места парковки.

Консольный прогон .NET-тестов (нужен .NET SDK 8+):

```
cd City/Tests && dotnet run -- 
```

Прогон не выполнялся; SDK в среде нет.

Unity: открыть сцену `CityTest`, на пустом объекте добавить `CityBootstrap`, в поле **Layout Id** выбрать `district750`, нажать Play. В Console появится строка «макет=district750, seed=1904».

## 4. Как подключить к CityTest

1. В сцене `CityTest` должен быть один пустой объект с `CityBootstrap`. Если его нет, добавить вручную (Add Component → CityBootstrap).
2. Для карты района: `Layout Id = district750`. Для старого квартала: `quarter250` (по умолчанию).
3. `Seed` оставить 1904 для воспроизводимости.
4. Программно: `var b = GetComponent<CityBootstrap>(); b.LayoutId = QuarterLayoutIds.District750; b.Generate();`
5. Повторный `Generate()` уничтожает предыдущий квартал (логика адаптера не менялась).
