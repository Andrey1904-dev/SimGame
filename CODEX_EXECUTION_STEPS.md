# Пошаговый план

На каждом этапе остановиться при ошибке/неизвестном API; не переходить дальше до выполнения критерия, не менять геометрию, сцену, экономические правила и посторонние системы. Коммит только после успешных проверок.

1. **Импорт** — `UNITY_IMPORT_MANIFEST.md`, `Economy/`, `Jobs/`, `Phone/`, `Debts/`, `UnityIntegrationKit/PhoneSources.cs`. Проверить конфликты, импортировать по манифесту, запустить Unity-компиляцию. Готово: без ошибок, без дублей, тесты отделены; остановиться при конфликте или недоступности редактора.
2. **EditMode** — `UNITY_TEST_EXECUTION.md`, четыре `*/Tests/`. Запустить полный пакет, прочесть XML и log. Готово: ненулевое число тестов, нет failures/ошибок; остановиться при нуле или падении. Не отключать тесты ради прохождения.
3. **Economy** — `Economy/Core/IWalletAdapter.cs`, `Economy/Shop/ShopService.cs`, `CODEX_WIRING_MAP.md`. Изучить реальные MoneyWallet и FoodInventory, подключить контракты без второго баланса; обеспечить атомарность покупки, компенсации и сохранения. Проверки spend/add/refund, сбой и повтор. Готово только при доказанной транзакционности; сейчас контракт без ID препятствует crash-safe защите: остановиться и согласовать решение, не маскировать его.
4. **Delivery** — `Jobs/Delivery/`, `UnityIntegrationKit/PhoneSources.cs`. Подключить реальные часы, location и durable wallet `IIdempotentPayoutAdapter`; IDs уникальны в истории save lineage. Проверить accept/pickup/complete, время и crash/retry, reconciliation при истечении срока. Готово только при атомарном durable журнале и сохранении; иначе стоп.
5. **Phone** — `Phone/Integrations/PhoneFacade.cs`, `UnityIntegrationKit/PhoneSources.cs`, `Phone/Apps/PhoneAppsSnapshot.cs`, `Phone/Contacts/PhoneBookSnapshot.cs`. Подключить services/данные и HUD после проверки существующего UI, sync badges; проверить отправку, прочтение, restore и просмотр заказов. Не дублировать данные модулей; stop при несовместимости сериализации.
6. **Debts** — `Debts/Core/DebtService.cs`, `Debts/Payments/IDebtWalletAdapter.cs`, `UnityIntegrationKit/PhoneSources.cs`. Подключить часы, устойчивые debit/refund/query, телефон; проверить платёж, штрафы, retry и восстановление сбоя. Готово: баланс и долг согласованы после рестарта; иначе стоп.
7. **Совместная проверка** — `CODEX_WIRING_MAP.md`, `SAVE_SYSTEM_INTEGRATION_PLAN.md`. Целевые end-to-end взаимодействия, сон/время, нет повторов операций, корректный HUD; ошибки или неконсистентность — стоп. Не менять сцену/экономику ради прохождения.
8. **Save System** — `SAVE_SYSTEM_INTEGRATION_PLAN.md` и конкретные DTO. Согласовать storage/версии/атомарную публикацию и migration; реализовывать только после утверждения архитектуры проекта. Проверить шесть сценариев документа и rollback. Готово при согласованном restore всех модулей и кошелька; иначе стоп. Не создавать параллельную систему сохранений без согласования.
