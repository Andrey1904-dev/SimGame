# Карта архитектуры (сигнатуры и детали — в указанных файлах)

Все модули без UnityEngine, интерфейсы в отдельных asmdef. Ошибки бизнес-операций возвращаются кодами результата; null обязательных адаптеров может бросать исключение. Конкретные адаптеры обязаны выполнять документированные атомарные контракты.

## Economy
`Economy/Shop/ShopService.cs`: `ShopService(IShopCatalog)`, `Purchase(IWalletAdapter,IInventoryAdapter,PurchaseRequest)`, `RetryPendingRefunds(IWalletAdapter)`, `PendingRefunds`, `RestorePendingRefunds(IEnumerable<Money>)`. `ShopCatalog`, `Product`, `PurchaseRequest/Result`; `Economy/Core/IWalletAdapter.cs`: `IWalletAdapter`, `IInventoryAdapter`, `Money`. `PendingRefunds` — только суммы, не устойчивые ID; события и полноценный снимок транзакций отсутствуют. Возврат и покупка не защищены от повторов через перезапуск. Зависимости: только Economy.

## Delivery
`Jobs/Delivery/DeliveryService.cs`: конструктор без параметров, `RegisterOrder`, `Accept`, `PickUp`, `Complete`, `Cancel`, `Abandon`, `Refresh`, `GetStatus`, `Orders`, `ActiveOrderId`; `IDeliveryService.cs`, `Adapters.cs` (`IGameClockAdapter`, `ILocationProvider`, `IPayoutAdapter`, `IIdempotentPayoutAdapter`). DTO `DeliveryOrder`, `DeliveryPoint`, `DeliveryResult/Status`, `DeliverySnapshot` и validator (`DeliverySnapshot.cs`). `CreateSnapshot`/`RestoreSnapshot(snapshot,out error)` на concrete, restore только в пустой сервис. Событий нет. ID выплаты `delivery:` + ID заказа; уникальность заказа в пределах истории сохранения обязательна. Cross-crash гарантия только при durable атомарном кошельке. `PaidRubles` при повторном подтверждении не доказывает новое начисление.

## Phone
`Phone/Integrations/PhoneFacade.cs`: `PhoneFacade(IPhoneAppRegistry,IPhoneMessageService,IPhoneBook,IPhoneNotificationService)`, `Inbox`, `Notifier`, `SyncMessageBadge`. `Phone/Apps/PhoneAppRegistry.cs` и `Phone/Contacts/PhoneBook.cs`: `CreateSnapshot`, `RestoreSnapshot(...,out error)` с полной проверкой, повторное восстановление заменяет состояние. DTO в соседних `PhoneAppsSnapshot.cs`, `PhoneBookSnapshot.cs`. `Phone/Messages/PhoneMessageService.cs`, `Phone/Notifications/PhoneNotificationService.cs`: `CreateSnapshot`; восстановление через `PhoneMessagesRestore` / `PhoneNotificationsRestore` `Validate` и `RestoreInto`. Их DTO immutable property-based, не предполагать сериализацию Unity JsonUtility: нужен проверенный сериализатор/конвертер. `Phone/Integrations/{PhoneBadgeSync,WorkSummaryService,BankSummaryService}.cs`, интерфейсы внешних источников в `Phone/Notifications/ExternalAdapters.cs`. Телефон не владеет балансом, долгами или заказами. События/уведомления — через предоставленные сервисы, не глобальный event bus.

## Debts
`Debts/Core/DebtService.cs`: `DebtService(IDebtClockAdapter,IDebtWalletAdapter,IDebtEventSink)`, `RegisterCreditor`, `CreateDebt`, `TryPay`, `UpdateTime`, `RetryPendingRecovery`, `GetDebts`, `CreateSnapshot`, `RestoreSnapshot`. `IDebtReadService`, `DebtView`, `DebtResult`; `Debts/Payments/IDebtWalletAdapter.cs` — устойчивый идемпотентный debit/refund/query. `Debts/Events/IDebtEventSink.cs`, `DebtEventHub.cs`, DTO `Debts/Persistence/DebtSnapshot.cs`, `DebtSnapshotValidator.cs`. Штрафы — `Debts/Penalties/`. Условия и ограничения восстановления — `Debts/INTEGRATION.md`. Телефон подключается только через read-only bridge.
