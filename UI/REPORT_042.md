## 1а. Что подключено к существующим системам (без копий правил)

| Система игры | Как подключена | Что осталось |
|---|---|---|
| `City.Pause` (`PauseController`/`PauseView`/`PauseKeyboardInput`) | `UiBootstrap` находит `PauseIntegration`, выключает вторые клавиши и второй `Time.timeScale`, действия меню идут в `PauseIntegration.Execute` | оставить одно меню паузы в сцене |
| `PauseDataSource` (время, деньги, потребности, цели) | `PauseUiSnapshotSource` читает `Read()` и подписывается на `Changed` | иметь наследника `PauseDataSource` в сцене |
| `Jobs.Delivery` (`IDeliveryService`) | `DeliveryServiceBridge`: список заказов, команды `accept/pickup/complete/cancel/abandon`, координаты точки из `QuarterPlan` | наследник `DeliveryServiceHost` + clock/payout/location адаптеры |
| Камера/игрок | `UiGameBridge`: `Camera.main` → любая включённая камера, честный `false`, если игрока нет | назначить `Player` и `Player Input Behaviours` |
| Сохранение/загрузка/меню | `UiMenuActions` + `IUiGameAction`; без исполнителя кнопка неактивна | реализовать `IUiGameAction` (если сохранения есть) |
| `QuarterPlan` (District750) | `IQuarterPlanSource` (без цикла сборок), `UiBootstrap.SetDistrictPlan` | ничего |

## 2. Проверки — что именно прогнано

```
python3 UI/Tools/checkui.py       → COMPILE: OK errors=0
python3 UI/Tools/checkeditor.py   → COMPILE: OK errors=0   (UI + Editor-установщик)
python3 UI/Tools/runtests.py      → 98/98 PASS, EXIT CODE 0
```

Что это доказывает: код синтаксически и типово корректен против стабов Unity,
логика (92 теста) проходит.

**Чего это НЕ доказывает:** что проект собирается в Unity (стабы ≠ Unity),
что UI выглядит как макет, что клики работают, что шрифты и батчи в порядке.
Ни в одном месте этого отчёта «компилируется стабами» не выдаётся за
«компилируется в Unity».

## 3. Что сделано по пунктам ТЗ

1. **Раскладка паузы по `Pause Menu.PNG`** — измерена (кадр 1672×941, полотно
   1920×1080, масштаб ≈1.1483), `PauseLayout.Validate()` → 0 замечаний, есть тесты
   на пропорции и на отсутствие наложений.
2. **Карта 750×750** — рисуется из данных района (`QuarterPlanAdapter` → меш), не
   из картинки. Почему нельзя взять `Map.PNG` — см. `UI/MAP_CALIBRATION_REPORT.md`
   (медиана расхождения 69.3 px ≈ 44.4 м, в допуск попадает 1 точка из 18).
2а. **Телефон ↔ доставка** — `DeliveryServiceBridge` подключает телефон к
   настоящему `Jobs.Delivery` (`IDeliveryService`), а не к копии правил: принять,
   забрать, доставить, отказаться; координаты точки доставки берутся из
   `QuarterPlan`; отказы объясняются игроку (`DeliveryPhoneCommands.Describe`).
   Нужны только компоненты-держатели: `DeliveryServiceHost`, `IGameClockAdapter`,
   `IPayoutAdapter`, `ILocationProvider` — все четыре уже есть в проекте как
   интерфейсы, реализации пишет интегратор.
3. **Маршруты** — граф 59 узлов / 82 ребра, связный; проверено, что **46 из 46**
   точек доставки District750 достижимы от дороги. Найден и исправлен настоящий
   дефект: раньше привязка была только к перекрёсткам и 17 из 46 адресов не
   маршрутизировались вовсе (до 75 м от дороги при допуске 45 м). Теперь —
   привязка к ребру + подход пешком последним участком.
4. **Телефон** — экраны, данные, разбор действий готовы; источник данных не
   подключён (см. §1).
5. **HUD** — подсказки и статус маршрута из `NavigationService`; данные — из
   существующего `City.Pause.PauseDataSource` через `PauseUiSnapshotSource`
   (мост готов, источник в сцене нужен один).
5а. **Сосуществование с `City.Pause`** — решён реальный риск двух меню на Esc:
   `UiBootstrap` находит `PauseIntegration`, переводит наш экран паузы в режим
   «вид существующей паузы», выключает у `UiRouter` свои клавиши и свой
   `Time.timeScale`, а действия `save/load/settings/...` передаёт в
   `PauseIntegration.Execute(...)`.
6. **Установщик в сцену** — `Tools → Life From Zero → UI → Install UI into game`,
   batch-режим `-executeMethod … InstallBatch`, `-lfzUiDryRun`, резервная копия
   сцены, отказ при чужом меню паузы, повторный запуск без дубликатов.
7. **Документация** — `UI/CODEX_EXECUTE.md` (что подключить, в каком порядке, как
   проверять), `UI/MAP_CALIBRATION_REPORT.md` (почему карта не из картинки).

## 5. Оставшиеся риски

* **Два меню паузы.** В проекте уже есть `City/Pause/*`. Пока старое меню не
  отключено осознанно, Esc может открыть два. Установщик в этом случае
  останавливается, а не решает за владельца.
* **Двойная обработка клавиш.** Если в игре свой роутер Esc/P/M — у `UiRouter`
  надо выключить чтение клавиатуры.
* **Карта не кликабельна.** Клик по карте не строит маршрут: у игры нет координат
  клика по миру. Ручная метка ставится в мире.
* **`QuarterUnityAdapter` вне проверки без Unity** — ошибки в нём ловит только
  компиляция Unity.
* **Стабы могут «переодеть» ошибку.** Если Unity-API используется не так, как в
  стабе, проверка это не увидит. Первый запуск Unity обязателен.
