Дата: 2026-11-05. Ветка: `arena/8bc423a2-simgame`.

## 1. Короткий вывод

Сделано: логика UI (состояния, карта, граф, маршруты, навигация, телефон, пауза),
мост «район → карта», рантайм-сборка экранов и идемпотентный установщик в сцену.

**Чего не сделано и почему это не «почти готово»:**

| Не сделано | Причина | Что нужно |
|---|---|---|
| Ввод позиции игрока в UI | в репозитории нет класса, знающего позицию игрока; придумывать его — значит подсунуть выдуманные координаты | интегратор: наследник `UiWorldAdapter` |
| Часы, деньги, долги, потребности в HUD | нет источника снапшота в коде игры | интегратор: наследник `UiSnapshotSource` |
| Телефон с реальными действиями | контракт `IPhoneDataSource` объявлен, реализации нет | интегратор поверх `PhoneFacade` + `Jobs.Delivery` |
| Принять/закрыть заказ из телефона | то же, `IDeliveryUiBridge` | интегратор |
| Проверка вида в Unity | Unity в среде нет: ни скриншотов, ни шрифтов, ни uGUI-кликов | запуск сцены человеком |
| Полигоны зданий на карте | из `QuarterPlan` их не получить без аппроксимации | вне ТЗ |

Пока строки из этой таблицы не закрыты, интерфейс **нельзя** называть
«подключённым к игре». Он готов как код и как логика.

## 2. Проверки — что именно прогнано

```
python3 UI/Tools/checkui.py       → COMPILE: OK errors=0
python3 UI/Tools/checkeditor.py   → COMPILE: OK errors=0   (UI + Editor-установщик)
python3 UI/Tools/runtests.py      → 92/92 PASS, EXIT CODE 0
```

Что это доказывает: код синтаксически и типово корректен против стабов Unity,
логика (92 теста) проходит.

**Чего это НЕ доказывает:** что проект собирается в Unity (стабы ≠ Unity),
что UI выглядит как макет, что клики работают, что шрифты и батчи в порядке.
Ни в одном месте этого отчёта «компилируется стабами» не выдаётся за
«компилируется в Unity».

## 5. Оставшиеся риски

* **Два меню паузы.** В проекте уже есть `City/Pause/*`. Пока старое меню не
  отключено осознанно, Esc может открыть два. Установщик в этом случае
  останавливается, а не решает за владельца.
* **Двойная обработка клавиш.** Если в игре свой роутер Esc/P/M — у `UiRouter`
  надо выключить чтение клавиатуры.
* **Карта не кликабельна.** Клик по карте не строит маршрут: у игры нет координат
  клика по миру. Ручная метка ставится в мире.
* **`QuarterUnityAdapter` вне проверки без Unity** — ошибки в нём ловит только
  компиляция Unity.
* **Стабы могут «переодеть» ошибку.** Если Unity-API используется не так, как в
  стабе, проверка это не увидит. Первый запуск Unity обязателен.
